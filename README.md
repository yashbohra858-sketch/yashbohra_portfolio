# Yash Bohra | Personal Portfolio

A hand-coded static portfolio (HTML, CSS, vanilla JavaScript). No build step, no frameworks, no dependencies besides Google Fonts (Bricolage Grotesque and Figtree), which fall back to system fonts if blocked.

## Files
- `index.html`, `styles.css`, `script.js`
- `assets/yash-bohra.png` (hero portrait)
- `assets/mumbai/` (three photos for the Mumbai journal)
- `assets/projects/adappt-concept.svg` (illustrative concept visual, **not** the real Adappt interface; labelled as such on the page)

## Preview locally
Open `index.html` in a browser, or for a more realistic preview run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Deploy free on GitHub Pages
1. Create a **public** repository on GitHub (e.g. `yash-portfolio`, or `<username>.github.io`).
2. Upload everything in this folder so that `index.html` sits at the repository root (not inside a subfolder). Keep the `assets` folder structure.
3. Go to **Settings > Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait one to two minutes. Your site appears at `https://<username>.github.io/<repo-name>/`.
